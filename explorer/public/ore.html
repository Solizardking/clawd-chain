ORE mining on clawd chain

We ported ORE v3.1.0, the proof-of-work version of ORE, to clawd chain (Agave 4.3.2 with Alpenglow). You hash on your own machine, submit proofs on-chain, and claim the cORE reward token. cORE is a test token with no value

How mining works

  • Hash. Your machine runs the drillx hash over your proof's current challenge and a nonce. No GPU farm needed, and the protocol accepts about one submission per minute per proof.
  • Difficulty. Difficulty is the number of leading zero bits in the hash. The program checks it on-chain and rejects anything under the minimum. Higher difficulty earns a larger reward (rewards scale by 2difficulty − min).
  • Rewards. Each valid hash is paid from one of 8 buses into your proof balance. Every ~5-minute epoch a reset refills the buses from the treasury and adjusts the base reward rate toward the target emission.
  • Claim. claim moves your proof balance into your cORE token account.
  • Noop. mine verifies the proof through a small noop program via instruction introspection. clawd chain uses its own noop at EHLnnh…wcts.

Try it

  1. Get CLAWD for fees from the faucet (69 CLAWD per wallet every 12h).
  2. Build the CLI from programs/ore on branch roadmap/ore.
  3. Open a proof, mine, and claim:
git clone -b roadmap/ore https://github.com/Solizardking/clawd-chain
cd clawd-chain/programs/ore
OPENSSL_NO_VENDOR=1 cargo +stable build --release -p clawd-ore-cli

export KEYPAIR=~/my-wallet.json RPC=https://rpc.clawdchain.trade
./target/release/clawd-ore open      # create your proof account
./target/release/clawd-ore mine 3    # ~1 hash/min, auto-resets each 5-min epoch
./target/release/clawd-ore status    # proof balance
./target/release/clawd-ore claim     # proof balance → your cORE token account

Why the v3.1.0 line

Current upstream ORE (v3.8.x) replaced hash proof-of-work with a board game where miners deploy SOL onto squares, and it depends on several extra programs. We ported the last proof-of-work release (upstream commit c89f73e8, Apache-2.0) so anyone can mine with a CPU. All PDAs derive from the new program ID, so the mint is new. The native CLAWD coin is untouched.
