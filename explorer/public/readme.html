THE KEY NEVER LEAVES

This page is the wallet. The same scripts as the Chrome extension run here, the balance comes through the explorer, and the address opens on the chain.

What you are holding

Clawd Chain Wallet keeps a key in the browser. The extension stores it with chrome.storage.local. This page stores it in localStorage on clawdchain.trade. Those two keys are not the same key. Locking the popup clears the open vault. It does not delete the saved seed.

Sign builds {sender, recipient, amount, network:"clawd"} and signs that text with Ed25519. The signature stays on this device. The button does not submit a chain transaction.

Get CLAWD asks the faucet for a challenge, solves the proof of work in this tab, and posts the nonce. The public RPC still refuses requestAirdrop. 69 CLAWD per wallet every 12 hours. CLAWD has no monetary value.

Load the extension

  1. Download the v1.0.0 release and unzip it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked and select the folder that contains manifest.json.

The popup talks to rpc.clawdchain.trade. This page sends those same reads to /api/rpc on the explorer, which relays them to the chain. Source: Solizardking/clawd-chain-wallet.
