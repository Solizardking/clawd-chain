What's inside

⚡ Full SVM

Agave runtime. Your Anchor programs, web3.js and the Solana CLI just work.

🦞 CLAWD gas

The native coin, 9 decimals. Free from the faucet, 5 per wallet per day.

🎨 NFTs ready

Metaplex Core and Core Candy Machine and Guard come preloaded at genesis.

🛡️ Fair use

Rate-limited public RPC (about 40 req/10s per IP). Heavy scans are disabled.

Quick start

solana config set --url https://clawd-validator-production.up.railway.app
solana-keygen new -o ~/clawd.json
# grab CLAWD at the faucet, then:
solana balance --keypair ~/clawd.json
solana program deploy target/deploy/my_program.so
