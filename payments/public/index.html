How to pay with x402Four HTTP steps. No accounts, no API keys.

Request the resource. You get back 402 Payment Required with a challenge listing the amount, payTo, feePayer and nonce.
curl -i https://payments.clawdchain.trade/resource
Build a transfer. Make a SystemProgram transfer of amount lamports to payTo, with feePayer set to the facilitator. Sign it as the payer only.
Retry with the proof. Send the base64 payment payload in the X-PAYMENT header (or PAYMENT-SIGNATURE).
Get the resource. The facilitator co-signs, submits and confirms the transaction, then returns the body with an X-PAYMENT-RESPONSE receipt that includes the transaction signature.
GET  /supported        schemes, network, feePayer, payTo
POST /verify           check a payment; never submits it
POST /settle           co-sign, submit and confirm
GET  /resource         demo paid resource (?scheme=mpp for the split)
GET  /discovery/resources   x402 discovery list of registered paid resources
GET  /registry/resources    · POST to register
